## 🛠️ Características del Programa

El sistema está dividido en módulos interactivos a los que se accede mediante un panel de **Login** (Usuario: `Admin`, Contraseña: `Admin`):

1.  **Módulo de Arreglos (CRUD de Vehículos)** 🚗: 
    *   Permite Insertar, Eliminar, Modificar y Buscar registros de vehículos deportivos (Placa, Propietario, Modelo, Tipo de Motor).
    *   Demuestra el manejo de memoria estática y validación de datos mediante expresiones regulares.
2.  **Simulador de Recursividad** 🔄:
    *   Una interfaz estilo "terminal/hacker" que permite visualizar paso a paso las llamadas recursivas de algoritmos clásicos como **Factorial** y **Fibonacci**.
3.  **Métodos de Búsqueda** 🔍:
    *   Ingreso dinámico de un arreglo de números por consola gráfica para probar algoritmos de **Búsqueda Secuencial** y **Búsqueda Binaria**.
4.  **Mini Pokédex (Métodos de Ordenamiento)** 👾:
    *   Un emulador visual de una Pokédex que demuestra los distintos algoritmos de ordenamiento (Burbuja, Selección, Inserción y Quicksort) ordenando los niveles de poder en tiempo real.
